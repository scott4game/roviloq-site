Roviloq

Privacy & support

Roviloq stores your jobs, resumes, source documents, personas, answers and reports on this device. It has no account, advertising or analytics SDK. Local files are excluded from backups; device loss or uninstalling may lose them. Keys use the device Keychain.

When you confirm an AI action, the selected text and code are sent directly to your configured provider. That provider’s privacy policies and API charges apply. Job-link loading contacts the source website without your API key. Speech recognition and screenshot OCR run on device; original speech audio is not saved. Shared screenshots are temporary until the role is saved or draft deleted.

You can delete local records by swiping left. Historical sessions retain independent snapshots; delete those sessions separately. Deleting local data cannot remove copies already processed by an external provider or shared elsewhere.

If a job link cannot be read, paste the full description or import screenshots. If speech is unavailable, type instead. For API errors, check the base URL, model, key and provider credit. Retry manually; canceled calls may still be billed.

AI feedback may be wrong. Personas simulate a source-based style, without the person’s endorsement. Code is not executed. No hiring outcome is guaranteed.
